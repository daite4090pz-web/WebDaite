Описание проекта
HOI4 Вики — веб-приложение в жанре фанатской википедии по игре Hearts of Iron IV.
Позволяет создавать, редактировать и систематизировать статьи об игровых механиках, странах, юнитах, технологиях и национальных фокусах.
Реализована полноценная авторизация, ролевая модель (пользователь / администратор), категоризация контента, поиск, комментарии и удобный визуальный редактор.

Проект написан на Python 3.14 с использованием Flask, SQLAlchemy, Flask-Login, Flask-WTF и CKEditor 5.
Интерфейс оформлен в тёмно-фиолетовой неоновой гамме, полностью адаптирован под требования задания.

🔥 Основные возможности
Регистрация и вход с шифрованием паролей (Werkzeug)

Статьи с визуальным редактором (жирный шрифт, цвет, таблицы, изображения)

Категории – гибкая система меток, каждая статья может принадлежать нескольким категориям

Страны, Механики, Юниты, Технологии, Национальные фокусы – отдельные сущности с привязкой к категориям

Поиск по всем типам контента (статьи, страны, механики, юниты, технологии, фокусы, категории)

Комментарии к статьям (только для авторизованных)

Админ‑панель: управление пользователями (смена прав, удаление), создание/редактирование любых объектов

Загрузка изображений – встроенный адаптер для CKEditor, картинки сохраняются в static/uploads

Случайная статья – переход на случайную страницу вики

Избранное – сохранение статей в localStorage браузера

Адаптивная вёрстка – широкий контейнер, горизонтальная прокрутка таблиц

Автоматические сиды – при первом запуске база наполняется стартовыми данными


🚀 Быстрый старт
Склонируйте репозиторий или скопируйте файлы в папку hoi4wiki.

Установите зависимости:

bash
pip install flask flask-login flask-wtf sqlalchemy werkzeug


Запустите приложение:

bash
python run.py
Откройте в браузере http://127.0.0.1:5000.

При первом запуске автоматически создастся база данных hoi4wiki.db и заполнится начальными категориями, странами, юнитами и т.д.

👥 Роли пользователей
Гость – просмотр статей, стран, механик, поиск

Авторизованный пользователь – создание и редактирование своих статей, комментирование

Администратор – доступ в /admin, может управлять пользователями, создавать/редактировать любые объекты, добавлять категории
